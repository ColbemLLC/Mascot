<h1 align="center">Colbem Engine</h1>

Colbem Engine is the core system powering Colbe, written in Rust. It handles rendering, processes large volumes of data efficiently, manages cleanup of leftover/stale data, and provides robust error handling across the platform.

## Requirements

- Rust (stable toolchain)
- Cargo
